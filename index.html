Kode Google Apps Script (Code.gs)

Pasang sekali di Google Sheets untuk sinkronisasi otomatis semua perangkat

Cara Pemasangan (Hanya 2 Menit):

  1. Buka Google Sheets baru di akun Google Anda (sheets.new).
  2. Klik menu Ekstensi (Extensions) → Apps Script.
  3. Hapus semua kode bawaan di editor, lalu tempel kode Code.gs di bawah ini dan klik ikon Simpan (Ctrl+S / Cmd+S).
  4. Klik tombol biru Terapkan (Deploy) → Deployment baru (New deployment).
  5. Pilih jenis: Aplikasi web (Web app) • Jalankan sebagai: Saya (Me) • Yang memiliki akses: Siapa saja (Anyone).
  6. Klik Terapkan (Deploy), izinkan akses Google, lalu salin URL Aplikasi Web (.../exec) dan tempel di kolom pengaturan Mahadewa.id!
